## 승인된 MCP 수명주기

개발 Core MCP 프로파일은 고정된 운영자 provider·source·context 팩토리를 통해
네이티브 수명주기를 제공합니다. 제안 결정과 적용은 각각 별도 정확한 승인이 필요하며
직전 네이티브 `artifact_sha256`를 `expected_sha256`로 전달합니다. 네이티브 주체는
고정하고 오래된 revision은 변경 전에 거부합니다. 모델의 workspace 경로·provider
자격증명은 받지 않습니다. [MCP 계약](../guides/mcp.md#네이티브-ai-제안-검토와-적용)을 참조하세요.
