# Truthound 3.3.2

Core 품질 계산과 데이터 권한을 변경하지 않고 MCP 클라이언트의 도구 발견과 Claude Desktop 패키징을 수정합니다.

## 수정 사항

- 재귀 모델 도구 스키마에 MCP가 요구하는 최상위 객체 타입을 제공하고 중첩 검증 조건을 유지합니다.
- 빈 Desktop 작업공간·운영자 제어 설정의 미치환 문자열은 권한 없음으로 처리하며, 필수 데이터 경로의 미치환 문자열은 거부합니다.
- Local·Core 번들은 서로 다른 확장 ID와 작은 아이콘을 사용합니다.

## 설치 및 배포 상태

Codex·Claude Code와 별도 Claude Desktop 확장의 설치는 [Styxis Plugins](https://github.com/seadonggyun4/styxis-plugin#install)에서 시작합니다. Code 플러그인 업데이트는 Desktop을 업데이트하지 않습니다. 기존 권한은 유지합니다.

Core 3.3.2와 대응 플러그인 업데이트는 준비 중입니다. 공개 게시와 실제 업데이트 설치를 검증한 뒤 배포 완료로 표시합니다. 로컬 `3.3.1+desktop.3` 복구본은 미게시 빌드였습니다.

## 검증

회귀 테스트는 재귀 스키마 동등성, 최상위 객체, 번들 ID와 선택 설정 처리를 확인합니다. 게시 전에는 공개 플러그인의 고정 설치와 별개로 격리된 구성에서 후보 wheel을 두 클라이언트 실행기로 검증합니다. 게시 후 PyPI 산출물로 플러그인 lock을 생성하고 해시·실행을 검증한 뒤 Styxis 카탈로그의 고정 소스 커밋을 갱신합니다.

MCP의 전체 Core 동등성은 여전히 미검증입니다. 도구 발견, 실행 성공, 데이터 품질 판정은 서로 구분합니다.
