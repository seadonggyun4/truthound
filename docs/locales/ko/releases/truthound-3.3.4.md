# Truthound 3.3.4

이 패치는 패키지와 공식 MCP Registry의 문서 링크를 커스텀 도메인으로 직접 연결합니다.

- [한국어 문서](https://www.truthound-docs.tech/)와 [영어 문서](https://www.truthound-docs.tech/en/)의 대표 주소는 `www.truthound-docs.tech`입니다.
- 이전 문서 주소는 페이지 경로를 유지하여 영구 리디렉션됩니다.
- Local과 Core의 설치 진입점은 [Styxis Plugins](https://github.com/seadonggyun4/styxis-plugin#install)입니다. 마켓플레이스와 설치된 플러그인을 업데이트하면 공개된 런타임 버전 고정을 받습니다.
- 검증 동작, MCP 도구와 권한 경계는 유지합니다. 설치만으로 데이터 접근 권한이 생기지 않습니다.

이미 게시된 배포 파일의 메타데이터는 그대로입니다. 대표 주소를 직접 받으려면 3.3.4로 업데이트하세요.
