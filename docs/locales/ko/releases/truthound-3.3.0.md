# Truthound 3.3.0

이번 릴리스는 선택형 Core 프로파일로 로컬 MCP 통합을 확장합니다. 패키지 게시,
클라이언트 마켓플레이스 등록과 배포는 별도의 검증 단계이며, 이 문서가 후보의 게시를
선언하지는 않습니다. 기존 기본 도구 세 개도 계속 제공합니다. 실행 명령, 운영자
바인딩, 동의와 서비스별 제한은 [MCP 가이드](../guides/mcp.md)를 확인하십시오.

## 설치와 핵심 작업

```bash
python -m pip install --upgrade "truthound[mcp]==3.3.0"
truthound-mcp serve --profile core --allow-dir /absolute/path/to/data
```

- 결측값·중복·범위와 합의한 스키마를 검증합니다.
- 컬럼을 프로파일링하고 PII를 탐지하며 원본을 바꾸지 않고 승인한 컬럼을 마스킹합니다.
- 스키마를 학습하고 보관한 기준·현재 데이터의 드리프트를 비교합니다.
- 결과 핸들을 읽고 해제합니다. 스키마 내용과 마스킹된 행에는 운영자의 명시적
  `--allow-sensitive-results` 권한이 필요합니다.

작업과 결과 해석은 [핵심 작업 안내](../guides/mcp.md#핵심-데이터-품질-작업)를
참고하십시오. 실행 성공과 데이터 품질 통과는 다릅니다. 스키마 검사의 전체 대상 적용
여부가 불완전하면 결과는 통과가 아닌 `unknown`으로 유지됩니다.

## SQL 시간 제한과 복구

- SQLite는 연결을 빌리는 범위마다 네이티브 progress handler로 시간 제한을 적용합니다.
  Python UDF 내부 실행은 중단할 수 없습니다.
- PostgreSQL은 네이티브 `statement_timeout`을 적용합니다.
- MySQL은 지원하는 읽기 전용 테이블 SELECT에 `max_execution_time`을 적용하고
  서버 측 커서 설정을 반영합니다. 모든 I/O에 적용되는 시간 제한은 아닙니다.
- Oracle은 왕복 호출별 시간 제한을 적용합니다. 풀이 연결을 다시 빌려주기 전에
  비정상 연결을 교체하며 실패한 문장을 재실행하지 않습니다.

기존 Core API·기본 MCP 도구 세 개·고급 기능은 유지됩니다. 이번 릴리스가 전체
Core/MCP 동등성이나 실제 클라우드 서비스를 인증하지는 않습니다. 3.2.0에 고정된
마켓플레이스 번들은 별도 배포물입니다.

## Core 작업과 네이티브 서비스

Core 프로파일은 데이터·결과·스키마·모델 핸들로 검증, 프로파일, 드리프트, 개인정보,
규칙 생성, 보고서와 계보를 처리합니다. 승인된 네이티브 팩토리로 데이터소스와 실행
엔진, 일반·스트리밍 저장소, 캐시, 코덱, 마이그레이션, tenant 정책, 플러그인,
체크포인트, 대시보드, 브로커, AI, 감사, 관측과 관리 기능의 수명주기를 제공합니다.
계산은 Core가 수행합니다. 민감한 산출물과 효과에는 구성한 공개 정책과 명시적 작업
승인이 필요하며, 요청에서 임의 Python import나 콜백을 선택할 수 없습니다.

영구 예약은 실행 전에 의도를 기록하고 중복 소유자를 차단하며 재시작 후에도 결과
불명 상태를 보존합니다. 전달 결과가 불명확하면 명시적으로 조정해야 합니다. 네이티브
추적 작업은 동기 콜백 전체에서 추적기와 context를 유지하고 성공·실패의 메모리 이력을
보존하며, 운영자가 지정한 그래프 파일을 저장·불러옵니다. 그래프 파일은 context
이력을 영속화하지 않습니다.

## 네이티브 정확성과 생성 산출물

준비된 Reflex 대시보드는 포트 검사나 프로세스 소유권 변경 전에 설정과 프로파일의
무결성을 확인합니다. 따라서 포트 충돌이 변조된 준비 설정 오류를 가리지 않습니다.

이 후보는 제한된 SQL 통계와 바인딩한 범위·집합 피연산자, null 그룹 중복 처리,
복사한 저장소 설정, 확인된 조건부 객체 저장, 캐시 정리와 불명확 쓰기 처리를 수정합니다.
네이티브 스캐폴딩은 따옴표가 있는 메타데이터를 보존하고 현재 reporter 계약으로
실행하며 공유 reporter 설정을 적용합니다. 벤치마크 비교는 서로 다른 suite를 거부하고
원본 측정 실패를 보존합니다.

계보 렌더러는 서로 다른 노드 식별자를 유지하고 삽입된 label과 JSON을 이스케이프합니다.
Graphviz SVG·PNG에는 `truthound[lineage-visualization]`과 시스템 `dot` 프로그램이
필요합니다. HTML 렌더링은 문서화한 라이브러리를 사용합니다. 파서와 네이티브 이미지
검증만으로 모든 브라우저의 대화형 동작까지 증명하지는 않습니다.

## 검증 범위

완전한 릴리스에는 같은 커밋의 전체 CI, 실제 네이티브 제공자 검사, 엄격한 영문·한국어
문서와 개인정보 검사, 정확한 wheel·sdist 해시, 새 환경의 클라이언트 설치와 배포 검증이
필요합니다. 과거 또는 일부 통과 결과로 이 기준을 충족하지 않습니다. 클라우드·브로커·
유료 AI·외부 알림 실계정은 별도의 검증이 필요합니다. Core 3.2.0에 고정된 기존 OpenAI
플러그인은 별도 배포물이며 새 Core 후보의 설치나 기능 범위를 증명하지 않습니다.
