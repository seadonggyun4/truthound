# Truthound 3.3.3

이 패치는 패키지의 문서 링크를 Vercel 문서 포털로 변경합니다.

- [한국어 문서](https://www.truthound-docs.tech/)와 [영어 문서](https://www.truthound-docs.tech/en/)는 같은 배포에서 제공됩니다.
- MCP 설치는 [Styxis 플러그인 마켓플레이스](https://github.com/seadonggyun4/styxis-plugin#install)에서 시작합니다.
- MCP Registry 메타데이터도 새 문서 주소를 사용합니다.
- 검증 동작, 도구 이름과 디렉터리 권한은 유지합니다. 설치만으로 데이터 접근 권한이 생기지 않습니다.

이미 게시된 패키지 파일의 메타데이터는 그대로입니다. 새 링크를 받으려면 이 버전으로 업데이트하세요.
