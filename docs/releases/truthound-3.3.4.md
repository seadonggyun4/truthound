# Truthound 3.3.4

This patch makes the custom documentation domain the direct package and MCP Registry destination.

- [English documentation](https://www.truthound-docs.tech/en/) and [Korean documentation](https://www.truthound-docs.tech/) use the canonical `www.truthound-docs.tech` domain.
- Previous documentation URLs permanently redirect while preserving page paths.
- [Styxis Plugins](https://github.com/seadonggyun4/styxis-plugin#install) remains the installation entry for Local and Core. Update the marketplace and installed plugins to receive the published runtime pin.
- Validation behavior, MCP tools and permission boundaries are unchanged. Installation grants no data access.

Published older distributions retain their original metadata. Upgrade to 3.3.4 to receive the canonical links directly.
